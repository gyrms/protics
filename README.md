# Protics

사내 직원 관리 시스템

## 프로젝트 구조

```
protics/
├── src/
│   └── main/
│       └── java/
│           └── com/protics/
│               ├── controller/
│               ├── service/
│               └── repository/
└── README.md
```

## 브랜치 전략

- `main`: 운영 브랜치 (직접 커밋 금지)
- `develop`: 개발 브랜치
- `feature/*`: 기능 개발 브랜치

## 커밋 컨벤션

```
feat: 새로운 기능 추가
fix: 버그 수정
docs: 문서 수정
refactor: 리팩토링
test: 테스트 추가
chore: 빌드, 설정 파일 수정
```
